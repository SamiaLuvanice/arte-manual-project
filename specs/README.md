# Especificações do Projeto (Specs)

Esta pasta contém as especificações de requisitos e funcionalidades do projeto **Arte Manual**. Qualquer nova funcionalidade, alteração complexa ou tela nova deve ter um arquivo correspondente aqui antes do desenvolvimento.

---

## 📂 Estrutura de Arquivos

- `template.md`: Modelo básico a ser duplicado para novas especificações.
- `xx_nome_da_feature.md`: Arquivos de especificação ordenados numericamente (ex: `01_landing_page.md`, `02_carrinho_de_compras.md`).

---

## 🔄 Status das Especificações

Cada arquivo de especificação deve declarar seu status no topo:

- 🔴 **Rascunho (Draft)**: Em fase de ideação.
- 🟡 **Em Revisão (Review)**: Pronto para feedback.
- 🟢 **Aprovado (Approved)**: Pronto para desenvolvimento.
- 🔵 **Implementado (Implemented)**: Código concluído e verificado.

---

## 💡 Como Criar uma Nova Spec?

1. Duplique o arquivo `template.md` e dê a ele um nome descritivo (exemplo: `specs/01_catalogo.md`).
2. Preencha todos os campos do modelo (Objetivo, UX/UI, Requisitos, etc.).
3. Mude o status para 🔴 ou 🟡 e discuta com o time/agente antes de iniciar o desenvolvimento.
